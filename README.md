## 🚀 Getting Started

To run the initial static website locally:

### 1. Clone the repository

```bash
git clone https://github.com/itech-ths/itech-ths-store.git
```

### 2. Open the project directory

```bash
cd itech-ths-store
```

### 3. Launch the website

Open `index.html` in a web browser.

For local development, a lightweight HTTP server can also be used.

For example, if Python is installed:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

These instructions apply after the website files have been added to the repository.
